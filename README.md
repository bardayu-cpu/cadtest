# cadtest · 户型图 → 实景效果图

项目目标：上传户型平面图，识别与编辑空间、布置家具、生成彩色平面图和室内全景效果图。

当前完成脚手架、Issue #2 数据模型及 Issue #3 上传与校准画布：可以新建、打开、删除本地项目，自动保存、导入导出 JSON，以及撤销重做项目修改。墙体等绘制工具、识别、家具布置、渲染和发布仍留给后续 Issue；四个 API 的 POST 返回 `501`。本阶段不需要 API Key，也不调用外部 AI 服务。

## 本地运行

推荐使用 **Node.js 24 LTS** 和 npm；`.nvmrc` 指定大版本 `24`，本地和 CI 使用同一版本线。测试工具的 Node 22 最低要求为 **22.12.0**，完整支持范围见 `package.json` 的 `engines.node`。使用 nvm 时先运行：

```bash
nvm install
nvm use
```

```bash
npm install
npm run dev
```

浏览器打开 <http://localhost:3000>。页面使用中文，样式由 Tailwind CSS 提供，不需要下载远程字体。

- `/`：本地项目列表，可新建、打开、删除、导入和导出项目。
- `/project/[id]`：步骤式编辑器，可上传底图、滚轮平移、Cmd/Ctrl 滚轮缩放、空格平移、调整透明度、显示/隐藏及手动校准；其余步骤为占位。保留名称修改、撤销重做及 JSON 导出；不存在的编号会显示中文提示。
- `/s/example`：全景查看占位页面。

生产构建与运行：

```bash
npm run build
npm start
```

`npm run format` 格式化代码，`npm run test:watch` 启动单元测试监听。GitHub Actions 在 push 和 PR 时使用 `npm ci` 安装锁定依赖，并运行上述三项检查。

Playwright 测试覆盖桌面和移动端视口的项目管理、刷新恢复、完整 JSON 导入导出、无效文件提示、撤销重做快捷键，户型图 EXIF 去除、缩放平移、校准精度和几何数据保留，以及 API 占位响应：

```bash
npx playwright install chromium

```

E2E 会自动启动和关闭开发服务器，需要 3000 端口空闲。首次运行需要下载 Chromium；单元测试不包含 E2E 文件。

本机已有 Google Chrome 时，也可使用 `PLAYWRIGHT_CHANNEL=chrome npm run e2e`，无需额外下载 Chromium（macOS / Linux）。

推荐在生产构建上进行完整回归，避免开发服务器按需编译影响页面加载，并验证实际发布版本：

```bash
npm run build
PLAYWRIGHT_USE_BUILD=1 PLAYWRIGHT_CHANNEL=chrome npm run e2e -- --workers=2
```

不设置 `PLAYWRIGHT_USE_BUILD` 时仍使用开发服务器；有 Chromium 时可省略 `PLAYWRIGHT_CHANNEL`。

## 项目数据与本地保存

项目只保存在当前浏览器的 IndexedDB，不上传到服务器；不同浏览器或设备不会自动同步。清理浏览器数据会删除本地项目，请通过「导出 JSON」保存备份。

- 从首页输入名称并新建项目，或选择 `.json` 文件导入。文件经过 Zod 校验，格式、版本、字段或引用不存在会显示带字段位置的中文提示，不影响已有项目；同编号项目需要确认才能覆盖。导入保留原编号及全部数据。
- 项目信息页支持修改名称，提供撤销、重做按钮和 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z 快捷键；输入框内保留原生文字撤销。
- 修改停止 400ms 后自动保存最后一次修改，页面显示读取、保存、完成或失败状态。页面隐藏、pagehide 或离开编辑页时立即发起保存；浏览器强制退出仍可能中止异步写入。索引或项目读取失败时禁用相应编辑，避免覆盖已有数据；保存失败保留当前修改，可以重试或导出备份。
- 编辑历史使用完整项目快照，保留最近 100 步；打开不同项目、离开项目页、导入或刷新页面会清空历史。项目新建、删除和导入不属于编辑撤销操作，删除与导入覆盖需确认。

`src/model/types.ts` 和 `schema.ts` 覆盖规格 §5 的所有字段，包括后续阶段使用的锚点、全景、识别报告和发布数据。`createProjectStore()` 提供独立 Zustand store，`ProjectProvider` 在浏览器挂载后读取存储，不在服务端共享用户状态。

Store 的 `add/update/removeWall`、`Opening`、`Room`、`Furniture`、`Anchor` action 操作当前项目；手动 update 自动将元素 source 改为 manual。删除墙体同时删除其门窗，删除锚点同时清理相关热点和全景；删除房间还会删除该房间的锚点及其热点和全景引用，并移除家具的 roomId（家具保留）。这些修改均作为一步撤销。`updateProject` 修改项目元数据；元素必须通过对应 action 修改。IndexedDB 每个项目保存为 `project:<id>`，`project-index-v2` 索引只含编号、名称和更新时间；首页读取索引，打开项目或从首页导出时才读取完整内容。项目记录与索引在同一事务更新；保存串行执行，`flush()` 立即发起待写操作并可等待保存结束，失败操作保留供重试。旧 `projects-v2` 键不迁移；图片独立 Blob 存储留到 P6。多标签页编辑同一项目暂以最后写入为准。

## 户型图画布与手动校准

打开项目后默认进入「编辑」步骤；识别、家具、风格、锚点、渲染、发布可切换查看占位说明。

1. 点击画布中央的上传区，或将图片拖入整个画布区域，也可 Cmd/Ctrl + V 粘贴截图；输入框保留原生粘贴。替换已有底图前会确认。支持 JPG、PNG、WebP（不超过 20 MB、边长 8192 像素、3200 万像素）。图片在浏览器中以原像素尺寸重绘为 PNG 后保存，不保留源文件 EXIF，也不上传到服务器。更换底图会重置底图比例尺为 1 mm/px、偏移为原点，已有几何数据保留。
2. 普通滚轮和触控板两指滑动平移；Cmd/Ctrl + 滚轮或触控板捏合缩放，缩放中心跟随鼠标；空格拖动仍可平移。上传后自动适应并默认锁定，点击「解锁视图」后才能平移或缩放。「适应画布」在锁定时也可用。锁定状态按项目保存在浏览器本地 UI 设置中。
3. 上传后，右侧卡片说明校准目的并高亮当前步骤：① 找一条标了数字的尺寸线；② 依次点击两端；③ 输入线上的毫米数字并「应用校准」。点击「开始选点」后显示十字准星，选完第一个点会有跟随鼠标的预览线和实时像素长度。底图比例尺按真实距离 / 原图两点的像素距离计算，缩放和平移不影响校准；重合或相距不足 1 像素的点、非正数距离会给出中文提示。
4. 完成后卡片显示「✓ 已校准」及「重新校准」。也可「稍后再校准」，状态栏会显示「尚未校准，尺寸仅供参考」。已校准标记按底图标识和比例尺保存于当前浏览器 UI 设置，不修改项目模型。可再次进入校准，在另一条已知尺寸线两端选点，用「当前两点距离」复核，然后取消校准。按 Esc 取消或用「重新选点」重选。重新校准仅更新背景 mmPerPixel，不改墙、门窗、房间、家具和锚点的毫米坐标。
5. 编辑器铺满窗口，顶部是紧凑的标题栏与步骤导航；右侧 280px 控件栏可以折叠，项目名称在「项目信息」中修改。1280×800 下默认展开侧栏时画布为 1000×724，占窗口 70.7%。透明度和底图比例尺参与项目保存及撤销重做。视口缩放、平移、显示/隐藏及未提交选点只属于当前画布会话，切换步骤或刷新后重新显示底图，不修改项目模型。

验收图 `fixtures/floorplan-a.jpg` 为 1264 × 921；上方 15040 尺寸线端点标注为 (123, 45)、(1091, 45)，下方复核为 (123, 874)、(1091, 874)，见 `fixtures/floorplan-a.calibration.json`。浏览器测试通过真实画布选点、15040 mm 校准、下方复测误差 < 1%、重新校准及刷新恢复，完整项目中的几何体深比较保持一致；另验证 EXIF 去除、拖放/粘贴及替换取消、滚轮手势/空格平移、锁定与刷新恢复、透明度、隐藏、错误上传、校准输入、三步引导、侧栏折叠和 1280×800 窗口面积。

### 墙体编辑

进入项目的「编辑」步骤，使用画布左上角的「墙」工具连续点击描墙，双击或 Esc 结束。右侧可选 240 / 120 mm 或自定义墙厚；起点之后可直接在画布键入长度再回车，也可在「下一段长度（mm）」中输入。默认正交，Shift 自由画线；10 屏幕像素内优先吸附已有端点，其次已有墙线。

「选择」工具点击墙后显示端点，拖动端点修改形状，拖动墙中部整体平移；Delete 或侧栏按钮删除墙及其门窗。每次拖动仅占一步撤销，Esc 取消当前拖动；墙厚修改、描墙、删除均支持 Ctrl/Cmd+Z 和 Ctrl/Cmd+Shift+Z。绿色为手动墙，蓝色为自动墙，置信度低于 0.6 为橙色。

底图校准不改变墙体毫米坐标，锁定视图也不禁止几何编辑。没有底图时也可从零描墙，并用「适应画布」查看所有墙体。当前只提供墙体工具，门窗、房间等编辑按后续 Issue 实现。`fixtures/floorplan-a.wall-trace.json` 是编辑器验收的手工描墙路径，不供识别算法使用。
